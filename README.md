# QU Studio 安装包

这个仓库只放 QU Studio 的 Mac 安装包和自动更新用的文件（Releases），不放代码。

- 官网：<https://qu.studio>（介绍、帮助中心都在这里）。
- 下载：到 [Releases](https://github.com/gavinguo521/qustudio/releases) 下载最新的 `QU-Studio-<版本>-arm64.dmg`（Apple 芯片）。
- 已经装好的 QU Studio 会在「设置 › 关于」里检查更新，自动从这里下载新版本。

## English

This repository only holds the QU Studio Mac installers and auto-update files (Releases), not the source code.

- Website: <https://qu.studio> (overview and Help Center).
- Download: get the latest `QU-Studio-<version>-arm64.dmg` (Apple silicon) from [Releases](https://github.com/gavinguo521/qustudio/releases).
- An installed QU Studio checks for updates under "Settings › About" and downloads new versions from here automatically.
